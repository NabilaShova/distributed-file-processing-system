# Installation

## Windows host

Project directory:

`C:\Users\shova\Projects\distributed-file-processing-system`

Use Python 3.12 and a virtual environment named `.venv`. Install the pinned packages in `requirements.txt`.

Copy `.env.example` to `.env` when a later phase connects to MariaDB. Keep the real password out of Git.

## Linux nodes

Each node already has Python 3.12.3. The application virtual environments are created in Phase 8. Do not install those environments by hand during Phase 2.
